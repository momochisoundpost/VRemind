# VRemind 1.3 ("Better Together") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split VRemind's platform-agnostic business engine into a pure-Foundation `VRemindCore` SwiftPM target bridged by `VRemindKit` for macOS, and add zero-API-key Twitch live stream support alongside YouTube with platform-badged watchlist UI, notifications, onboarding, and desktop widgets.

**Architecture:** `Package.swift` separates `VRemindCore` (pure `Foundation` + `#if canImport(FoundationNetworking)`) from `VRemindKit` (`@_exported import VRemindCore`, hosting `ObservableObject` stores, `NSWorkspace` sleep/wake, `UserNotifications`, `WidgetKit`, and SwiftUI views). Inside `VRemindCore`, a `StreamProvider` protocol and `StreamProviderRegistry` dispatch `YouTubeStreamProvider` and key-free `TwitchStreamProvider` fetches through a pure `StreamMonitorEngine`, while `VRemindKit` bridges events, `UserDefaults` migration, and UI updates to `VRemind` and `VRemindWidget`.

**Tech Stack:** Swift 5.9, Foundation / FoundationNetworking, SwiftUI, AppKit, Combine, UserNotifications, WidgetKit, Swift Testing (`Testing`), Xcode Command Line Tools (`./scripts/test.sh`, `./scripts/build-app.sh`).

**Spec:** [docs/superpowers/specs/2026-11-12-vremind-1.3-better-together-design.md](file:///Users/karyl/CaitDev/CaitlynSwift/docs/superpowers/specs/2026-11-12-vremind-1.3-better-together-design.md)

## Global Constraints

- **Deployment Target:** macOS 12.0+ (`.macOS(.v12)`), Universal (`arm64` + `x86_64`), Swift 5.9+, built with Xcode Command Line Tools only (no full Xcode IDE).
- **Zero Dependencies & Zero API Keys:** Zero third-party SwiftPM packages; both YouTube and Twitch work without user-supplied API keys or OAuth tokens.
- **Strict `VRemindCore` Portability:** `Sources/VRemindCore` may import only `Foundation` (plus `#if canImport(FoundationNetworking) import FoundationNetworking #endif`) and must not import `AppKit`, `SwiftUI`, `Combine`, `UserNotifications`, `ServiceManagement`, `WidgetKit`, or call unguarded `autoreleasepool`.
- **Concurrency & Power:** Preserve bounded batch concurrency of `3` channels per batch, ephemeral cache-free `URLSession`, and `NSWorkspace` display sleep/wake pause/resume.
- **Deferred Scope:** Kick and RSS are out of scope for 1.3 (preserve `StreamProvider` / `StreamPlatform` extensibility).

## Review Focus

1. **Legacy 1.2 `UserDefaults` & `widget-cache.json` upgrade compatibility:** Saved v1.2 `WatchedChannel` payloads (missing `platform`, `id` like `"@bukancaitlyn"`) and cached `WidgetChannelItem` JSON must decode as `.youtube`, migrate `id` to `"youtube:@bukancaitlyn"`, and preserve `lastNotifiedVideoId`, `lastNotifiedUpcomingId`, `lastStreamedAt`, `name`, and `avatarURL`. *(Pinned in Task 1, Task 4, Task 5)*
2. **Cross-platform handle collision & avatar cache isolation:** Tracking the same handle on both YouTube (`@ironmouse`) and Twitch (`ironmouse`) must remain two distinct watchlist entries, distinct `WidgetChannelItem.id`s (`youtube:@ironmouse` vs `twitch:ironmouse`), and separate cached avatar files (`youtube_ironmouse.jpg` vs `twitch_ironmouse.jpg`). *(Pinned in Task 1, Task 4, Task 5)*
3. **Twitch handle normalization & smart URL auto-detection:** Inputs like `"twitch.tv/IronMouse/schedule?foo=1"`, `"@IronMouse"`, invalid logins (`"bad-dash"`, `""`, 26-char string), or pasting a Twitch URL while the add-bar dropdown is set to YouTube must normalize/auto-switch accurately without breaking existing YouTube handle/URL parsing. *(Pinned in Task 1, Task 2, Task 6)*
4. **Twitch GraphQL error, missing-user, and malformed-JSON resilience:** `TwitchStreamProvider` receiving HTTP non-2xx responses, GraphQL `errors`, `"user": null`, or malformed JSON must yield failure / `.unrecognized` (mapped to `.unknown` status) without crashing or overwriting existing `name` or `avatarURL`. *(Pinned in Task 2, Task 4)*
5. **Strict `VRemindCore` portability & platform-aware click-through URLs:** `Sources/VRemindCore` must have zero Apple UI/system framework imports, and clicking a Twitch channel row, notification (`watchURL`), or widget must open `https://www.twitch.tv/<handle>` instead of a YouTube watch URL. *(Pinned in Task 3, Task 4, Task 5, Task 6, Task 7)*
