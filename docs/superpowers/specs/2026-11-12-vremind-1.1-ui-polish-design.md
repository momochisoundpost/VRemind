# VRemind 1.1 UI Polish Design Specification

- **Date:** 2026-11-12
- **Target Release:** 1.1 (Stable)
- **Status:** Approved (Approach 1)

---

## 1. Intent & Context
VRemind 1.1-beta introduced macOS desktop widgets. Following visual testing on live macOS desktop setups, several key refinements are required for the 1.1 stable release:
1. The **Small Hero widget** (`systemSmall`) creator avatar currently sits inside an inset container margin. It must fill the entire widget bounds edge-to-edge (`.scaledToFill()`) with a clean crop, presenting a true full-bleed hero card.
2. In macOS Sonoma / Sequoia, when desktop widgets are unfocused (an application window is active) or when monochrome styling is active, the desktop widget tints light gray/cream. White text on this light background completely loses contrast; the text and badge elements must switch to high-contrast black so creators' statuses remain glanceable.
3. In the **Menu Bar Popover**, hovering over a VTuber row should display a pointing hand cursor (`NSCursor.pointingHand`) rather than a standard arrow to provide clear tactile feedback that the row is clickable.
4. Creators with long handles (e.g. `@sayaayaau...`) truncate with ellipses in the menu bar row. Hovering over the handle must show a native macOS tooltip revealing the full handle string.
5. The **Large Dashboard widget** is already confirmed perfect and must remain **strictly untouched**.

---

## 2. Goals, Non-Goals & Anti-Goals

### Goals
- **Full-bleed Avatar**: Small hero widget displays creator avatar edge-to-edge without container margin gaps.
- **Adaptive Monochrome Contrast**: Text, stream titles, and status indicators in the small widget render in high-contrast black when desktop is unfocused/monochrome (`widgetRenderingMode == .accented` or `.vibrant`), while retaining crisp white typography in full-color mode.
- **Pointing Hand Cursor**: Channel rows in the menu bar popover switch cursor to `NSCursor.pointingHand` on hover.
- **Full Handle Tooltip**: Channel handles in the menu bar row expose the full handle via native macOS `.help(...)` tooltip.
- **100% Test Coverage & Backward Compatibility**: All 163+ existing unit tests pass, new tests verify contrast logic and view attributes, and macOS 12+ compatibility is preserved.

### Non-Goals
- Do NOT touch `LargeDashboardWidgetView.swift`.
- Do NOT alter YouTube scraping or network polling logic.
- Do NOT introduce any third-party dependencies.

### Anti-Goals
- Do NOT use global margin removal that breaks the layout of the large dashboard widget.
- Do NOT leak cursor pushes onto the `NSCursor` stack when rows disappear or popover closes.

---

## 3. Approaches Considered

### Approach 1: Native WidgetKit Container Background & `widgetRenderingMode` (Selected)
- **Implementation**:
  - Small widget utilizes `.containerBackground(for: .widget)` (via availability-checked extension) to place the avatar and gradient scrim into the system's full-bleed background layer.
  - Detects `@Environment(\.widgetRenderingMode)` in `SmallHeroWidgetView`. When in `.accented` or `.vibrant` mode, typography and status badge switch to solid black.
  - Adds a safe `.pointingHandCursor()` modifier with `.onHover` push/pop and `.onDisappear` cleanup in `ChannelRowView.swift`.
  - Attaches `.help("@\(channel.handle)")` to the channel handle text.
- **Trade-offs**: Requires backward-compatible Swift extensions for macOS 12/13 vs macOS 14+, but cleanly isolates changes to the small widget without impacting the large widget.

### Approach 2: Global Configuration Margin Removal
- **Implementation**:
  - Apply `.contentMarginsDisabled()` globally to `StaticConfiguration` in `VRemindWidget.swift` and manually re-pad every widget size.
- **Trade-offs**: High risk of shifting the Large Dashboard widget layout which the user confirmed is already perfect. Rejected.

---

## 4. Detailed Component Design

### 4.1 Small Hero Widget (`SmallHeroWidgetView.swift`)
1. **Full-Bleed Container**:
   - Provide `widgetContainerBackground` helper that conditionally applies `.containerBackground(for: .widget)` on macOS 14+ and `.background` on macOS 12/13.
   - The avatar image is scaled to fill (`.aspectRatio(contentMode: .fill)`), clipped to the container shape.
2. **Monochrome / High Contrast Detection**:
   - Declare `@Environment(\.widgetRenderingMode)` (guarded by availability or custom adapter).
   - Compute `isMonochromeMode: Bool`: true when rendering mode is `.accented` or `.vibrant`.
   - Typography color: `isMonochromeMode ? Color.black : Color.white`.
   - Live / Upcoming badges: adapt to high-contrast dark foreground when in monochrome mode.

### 4.2 Menu Bar Popover (`ChannelRowView.swift`)
1. **Cursor Management**:
   - Create a reusable `PointingHandCursorModifier` using `.onHover` with tracking state and `.onDisappear` safety pop.
   - Apply `.pointingHandCursor()` to the channel button.
2. **Tooltip**:
   - Add `.help(formattedHandle)` to `Text(channel.handle)` and the channel header `HStack`.
